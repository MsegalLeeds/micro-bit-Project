# Device team

Open [the micro:bit Python editor](https://python.microbit.org/), paste the contents of [main.py](main.py) into the editor, connect your board by USB and send the program to it. Open the serial console and press button A twice. The LEDs show the last digit of the count. The console should print:

```text
button_a,1,presses
button_a,2,presses
```

Copy those lines into the web dashboard. Save device source changes here so teammates can edit and flash the same program. If your group uses MakeCode, commit its editable source in this folder and document how to open it. Both editors can produce the [shared reading format](../shared/README.md).
